Settings

Network, API access, sign-in and server storage.

Network

Devices try the address that answered last, then the other one. Addresses are sent when a device is invited. Current firmware pulls when the server announces new readings; this interval applies to older firmware, after failed pulls and as grace before Updates missing, and reaches paired devices with their next pull. An empty internal address is derived from the host used to open this page.

Read-only API access

One IP address or CIDR range per line, for example 192.168.2.0/24. An empty list blocks all access. Forwarded IP headers are ignored.

Legacy connection to manually configured devices

The device must be in Wi-Fi mode and reachable over LAN or VPN. Enabled delivery periodically writes display frames to /frame. A pairing token must already exist for this device. No automatic pairing, no Wi-Fi changes and no flashing.

Administration sign-in

User admin. A password set here replaces ADMIN_PASSWORD from the environment (.env) until it is reset.

Hardware display colors

Live color comparison

The first matching size rule applies. Both dimensions must fit. Displays without a matching rule use full colors. Web displays and browser previews always keep full colors.

32 and 64 colors reduce transfer size most. Important weather and theme-icon colors share the palette budget; gradients may lose some shades. Requires compatible firmware; older firmware keeps RGB565.
