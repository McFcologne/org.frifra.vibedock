Update interval

Dynamic
Dynamic learns for every source how often its provider answers: each rate limited answer (HTTP 429) adds a minute, up to the longest interval; after an hour without one it tries a minute less, down to the shortest. If that shorter interval is rate limited again, the source waits two, then four hours before the next try. Fixed asks at the shortest interval; a rate limited answer doubles the interval, up to the longest, and every following answer halves it again.
