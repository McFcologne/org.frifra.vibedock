Troubleshooting

The display's log shows what it did since its last starts: Wi-Fi, pairing, server answers and why a connection failed. It holds no keys or passwords. What the lines mean: Troubleshooting a display.

Server log

Recent server activity and errors: up to 500 lines from the last 256 KiB. Opens at the latest entry. Scroll up to read without following new entries.

Display log over USB

  
Connect the display by USB and close other programs that use its serial port. Works with every board and every display, paired or not;
    opening the port does not restart it. The log is kept on the server with the display's other logs.

  
Reading over USB needs Chrome or Edge on a computer and the administration opened over
    HTTPS or on localhost (Web Serial).

    Support file
    
  
    One file with what a problem needs: version and platform, the data sources (no sign-ins or keys), the displays, the server and
    access log of the chosen days and the saved display logs. Keys, tokens, links and e-mail addresses are removed. It is encrypted with
    a key that is shown once here: attach the file to the issue, and send the key separately, never in the issue.
    
  
    The file holds the logs saved so far. To add the current ones first, ask the displays for them:
      nothing is read from a display without this.
