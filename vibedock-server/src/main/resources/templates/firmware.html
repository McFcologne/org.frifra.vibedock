Own firmware build

Uploaded Build , uploaded , replaces the built-in firmware of this board for USB and for updates over Wi-Fi.

Upload a build of your own, e.g. a test version: and flash.bin from the same folder (the USB image with bootloader and partition table). The server reads version and board from the file, signs it with its key for updates over Wi-Fi and offers it to the devices of this board until you go back to the built-in firmware. Only upload firmware you built from these sources and trust: the devices install it.

Install from the browser

The browser flasher (esptool-js) is not part of this installation.

Flashing from the browser needs Chrome or Edge on a computer and the administration opened over HTTPS or on localhost (Web Serial). Open it that way, or use the commands below.

  1. Connect the display by USB and close other programs that use its serial port.
    Display log

    Not connected.

  2. Back up the whole flash of this device and keep the file private: it is the only way back to its current firmware and contains its Wi-Fi and pairing data.
  3. Install . The device restarts afterwards and keeps its settings.

Pair this device now?

The display gets your Wi-Fi and this server's address over the cable and shows its image right after its restart: no setup Wi-Fi, no pairing code. The Wi-Fi password goes from this browser to the device only; the server never sees it.

This page is opened on localhost, so the server's LAN address is unknown to it. Set the internal address under Settings first, otherwise the device cannot reach the server.
