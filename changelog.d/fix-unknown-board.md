- **Own builds are recognised and never get another board's firmware:** a display that reports a board ID this server does not know (a firmware built for an own board) keeps that ID (*Own build: <id>*) instead of counting as a VibeTV M1, and is never offered firmware, so it cannot receive the M1 image over Wi-Fi. Screen sizes between 64 and 480 pixels per side that a display reports are accepted as its display type (before, only the sizes of the built-in list); the design editor offers them.
