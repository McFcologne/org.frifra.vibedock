- **Raspberry Pi Pico 2 W with Waveshare Pico-LCD-1.3 (prepared).** New board `rpi-pico2w-lcd-13` (RP2350, 1.3" ST7789 240 × 240): the firmware builds for it on the Arduino-Pico core (`pio run -e rpi-pico2w-lcd-13`) and is installed by copying `firmware.uf2` onto the board in BOOTSEL mode. https uses TLS 1.2 with the full check against the root from pairing. Not run on hardware yet; no updates over Wi-Fi, no battery, the keys and the joystick are not used.
