- **The server can download firmware from releases.** Once after it starts and then every day it fetches the newest firmware from the GitHub releases of the sources in `firmware-sources.yaml` (the official one without a file; further repositories for alternative firmware can be added, in order of priority), checks every file against the SHA-256 and size of the release's `index.json`, and uses it when it is newer than the one built into the image. Firmware of a source that is not `trusted: true` is for USB flashing only, never for updates over Wi-Fi. `FIRMWARE_SYNC=false` turns the downloads off.
