- **Fewer external detours while the server answers slowly (firmware):** when the server accepts the connection but the HTTP answer is missing, the display retries the same address and tries the next one (the external HTTPS address) only after six such failures in a row, instead of at every failure. In a network without internet that detour cannot succeed, and each failed TLS attempt used up memory on the VibeTV Classic. The external address is still tried at once when the first address does not accept a connection at all.
