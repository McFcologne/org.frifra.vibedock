- **Theme icons (toward 0.4):** the design editor can retain the existing emoticon/None choice, follow a theme's
  default icon, or keep a fixed icon from the theme catalog. All 35 themes include original vector defaults; the
  prior illustrations remain available. Existing designs are unchanged. The first opt-in over an existing
  configuration creates a private rollback snapshot. Missing fixed references retain their selection and fall
  back to the stored emoticon. Package icons use bounded PNG/SVG validation and authenticated raster previews;
  no client firmware change is needed.
