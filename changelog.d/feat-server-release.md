- **Server and firmware are released separately.** The server has its own tags (`server-vX.Y.Z`) and releases with the JAR and the Docker image; the firmware keeps its `client-v` releases. The image no longer carries firmware and builds without the PlatformIO stage, so it is much faster to build: the server downloads the firmware from the client releases after its start. Until the first `server-v` tag exists, the plain version tags still give the server's version.
