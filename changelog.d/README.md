# Release notes of unreleased changes

Every pull request adds its release notes here as a file of its own, named after its branch (for example
`feat-touch-turn.md`): one or more bullets in the style of `CHANGELOG.md`. Separate files do not conflict, so pull
requests can be merged in any order.

For a release (see `RELEASING.md`), the bullets of all files here go into the new section `## X.Y.Z` of
`CHANGELOG.md`, below a short introduction that says what changed and what to update. Then these files are deleted,
except this README.
